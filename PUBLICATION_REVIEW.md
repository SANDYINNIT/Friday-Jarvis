# Publication status

This source preview was rebuilt as a fresh Git root from the reviewed Windows/Linux staging files. Application files matched the separately sanitized export. The older Git directory, original working files and prior export were preserved in a private recovery directory outside this checkout.

The source includes the AGPL project license, the patched Open Interpreter license and corresponding Python source, both platform installers, explicit private provider configuration and fake-provider tests. Reserved-rights Town artwork, its generator and dependent visual page are excluded. Linux provides a terminal experience. Windows retains the native source and installer. Consult docs/PLATFORMS.md for the accepted and unverified behavior.

A read-only authenticated review found the existing public GitHub repository has one branch, main, no tags, no forks and no pull requests. Only the owner account was listed as a collaborator. That main points to the old private history. The owner explicitly approved replacement of that exact branch tip after the new commit passes scanning. No unrelated branch or tag is a replacement target.

Replacing a ref cannot prove sensitive content has vanished from GitHub caches, retained objects or third-party clones. The remaining owner procedure is in docs/GITHUB_HISTORY_REMOVAL.md. No real credential was confirmed by scanning, and unknown historic credentials require owner review and rotation if they were real.

This package is a source preview with transparent limits. Clean Linux execution, a fresh Windows account and live audio/model/integration behavior were not established by this publication pass. Source and packaging checks use no personal credentials or devices.

Current evidence is recorded in packaging/publication-scan.json and packaging/publication-verification.json. Their scope and limits remain separate from remote cleanup.
